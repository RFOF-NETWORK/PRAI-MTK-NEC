PRAI/MTK/NEC — Banking rApp (Demo)

This is a lightweight web demo for the Banking rApp. It contains validators and describes flows. No private keys are present here.

Capabilities

  • IBAN (ISO 13616) validation and normalization (EU/DE focus)
  • Destination address validation (crypto address checksum + IBAN)
  • Tx proposal flow: propose → sign (in app) → submit
  • Escrow / audit mapping (off‑chain for fiat; on‑chain Escrow contract for token custody)

Quick Test

Example IBAN validator (client‑side only): enter an IBAN and click Validate.
